# GD Macro Vault 📦

Welcome to **GD Macro Vault**, the ultimate web-based repository and platform dedicated to Geometry Dash macro files. Designed with performance, accessibility, and sleek aesthetics in mind, this project provides a centralized hub for players to share, discover, and download automation and botting files seamlessly.

---

## 🌟 Key Features

* **🌍 Live File Repository:** Instantly browse and search through macro files hosted directly on your GitHub repository, alongside external community sources like MacroDash.
* **⚡ Direct Macro Upload:** Easily publish new macro files to the platform using an intuitive drag-and-drop or file-selection interface equipped with secure Vercel backend integration.
* **🔍 Advanced Format Filtering & Search:** Instantly filter files by specific extensions or search through titles in real-time to find the exact run you need.
* **💱 Integrated Macro Converter:** Quick, direct access to Nattie's online macro conversion tool to effortlessly switch files between different bot formats.
* **📱 Progressive Web App (PWA) & Mobile Support:** Fully responsive design optimized for standard web browsers as well as custom mobile application wrappers.
* **🛠️ Owner Control & Management:** Built-in administrative capabilities allowing authorized owners to securely manage and remove files directly from the live interface.

---

## 📂 Supported Formats

GD Macro Vault supports a wide array of macro and bot file extensions utilized across the Geometry Dash community to ensure maximum compatibility:

* `.gdr` (Geometry Dash Recorder)
* `.gdr2` (Geometry Dash Recorder v2)
* `.echo` (Echo Replay)
* `.json` (Standard JSON format)
* `.bot` (Generic Bot format)
* `.ybot` (YBot Replay)
* `.slc` (Clickbot / Select format)
* `.tcm` (TasBot Custom format)

---

## 🚀 Getting Started & Deployment

This application is built with standard web technologies (`HTML5`, `CSS3`, `JavaScript`) paired with serverless functions for GitHub API interactions.

1. Clone or download the repository.
2. Configure your GitHub repository parameters and credentials within the script files.
3. Deploy effortlessly onto hosting platforms like **Vercel** to enable seamless file uploading and live updates.
