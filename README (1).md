## 🌟 About The Project

**GD Macro Vault** is a lightweight, responsive web application designed for Geometry Dash players and creators. It aggregates macro files from multiple sources, allowing users to easily search, filter, and download macros for various bots and tools directly from their browser or mobile device.

---

## 📂 Supported File Formats

Our vault supports a wide range of standard Geometry Dash macro and level formats:

*   `📍 .gdr` / `.gdr2` (Standard replay formats)
*   `⚡ .echo` (Echo Replay)
*   `📝 .json` (Custom data structures)
*   `🤖 .bot` (Bot recordings)
*   `💎 .ybot` (YBot macros)
*   `🗺️ .slc` (Startpos Switcher / layouts)
*   `⏱️ .tcm` (TAS Bot / custom macros)

---

## ✨ Key Features

*   **🌍 Multi-Source Aggregation:** Automatically pulls live macros from your personal repository and external repositories (like MacroDash) in real-time.
*   **🛠️ Owner Dashboard:** Direct in-browser file management using the GitHub API (upload and delete files instantly without leaving the site).
*   **🔍 Instant Search & Filters:** Filter files by category chips or search by name instantly.
*   **📱 Mobile-First Design:** Fully optimized for mobile browsers and custom native app wrappers (PWA/APK).
*   **🔒 Secure Local Auth:** Owner tokens are safely stored in your browser's `localStorage`.
